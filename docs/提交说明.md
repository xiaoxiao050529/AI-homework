# 提交说明

建议最终提交以下材料：

1. `2023013015-许晴川.pdf`
   这是最终实验报告，当前由 `python -m scripts.generate_report` 生成在根目录。
2. 实验代码目录或其压缩包
   建议至少包含 `README.md`、`requirements.txt`、`scripts/`、`src/`、`data/`。
3. 关键实验结果
   建议至少保留 `outputs/experiment_summary.json`、`outputs/*_metrics.json`、`outputs/report_assets/`，便于复核。

## 复现实验

```bash
.venv/bin/python -m scripts.run_experiments
.venv/bin/python -m scripts.generate_report
```

## 当前目录口径

- `scripts/`：所有入口脚本
- `src/`：核心实现
- `data/`：训练数据、词向量、外部测试数据
- `docs/`：说明文档
- `outputs/`：实验产物
